# Zeus QA feature factory

A 20-slide deck: a factory of AI agents cloned a competitor's features into Zeus QA over 42.1 hours and merged 17 pull requests. How the line worked, what broke and what it cost at list price.

Live: https://smakosh.github.io/zeus-qa-factory-deck/

## Keys

- Right arrow, Page Down or Space: next slide
- Left arrow, Page Up or Shift+Space: previous slide
- Home / End: first / last slide
- F: full screen
- T: switch light and dark theme

Link to a slide with its number, e.g. `#7`. On phones the slides scroll.
